# 工作流程与执行规范

## 目录约定

```text
D:\视频素材\快捷指令\
├─ 参考影片\
├─ 标题\
│  ├─ 第一批.txt
│  ├─ 第二批.txt
│  └─ 第三批.txt
├─ 素材\
│  ├─ 快捷指令素材\
│  └─ 拍摄录屏\
├─ 音乐\
└─ 成品\
   └─ _edit\
```

允许用户更换项目根目录，但保持相对目录含义。

## 1. 安全检查与素材盘点

- 检查 `ffmpeg`、`ffprobe` 是否可用。
- 递归列出上述目录中的媒体文件，不要假设文件名、数量或扩展名。
- 用 `ffprobe` 获取每条视频的分辨率、方向、帧率、时长、视频编码和音轨情况。
- 三个标题文件应分别统计编号标题数量。忽略仅含“第一批/第二批/第三批”的标题行，正文行通常形如 `1. 标题内容`。
- 不改动用户原素材，不覆盖已有成品；同名成品需要重做时，先确认它确实属于本批任务。

## 2. 参考影片分析

从 `参考影片` 读取节奏和视觉关系，重点判断：

- 标题在画面中的安全位置与字号感；
- 快捷指令片头如何过渡到实拍使用场景；
- 拍摄、识别等待和热量结果各保留多少信息；
- 音乐起点、节拍和收尾方式。

参考影片只用于学习结构。标题必须来自用户的三批标题库，素材必须来自用户指定的素材目录。

## 3. 轮换策略

在 `成品\_edit\rotation-state.json` 保存轮换记录。建议结构：

```json
{
  "title_batch_order": ["第一批", "第二批", "第三批"],
  "next_title_batch": "第一批",
  "used_titles": [
    {"batch": "第一批", "number": 9, "video": "乐事薯片.mp4"}
  ],
  "last_intro": "快捷指令素材01.mp4",
  "last_music": "music01.mp3"
}
```

规则：

1. 标题批次按第一批 → 第二批 → 第三批循环。
2. 在当前批次内选择与食品或减脂场景匹配、尚未使用的标题；只有没有合适未用标题时才复用。
3. 每完成一条视频后才更新状态，避免失败渲染消耗轮换项。
4. 片头和音乐按文件名稳定排序后轮换。有多个候选时，不连续使用上一次的文件。
5. 只有一个片头或一首音乐时允许复用，并在交付说明中如实注明。

## 4. 建立剪辑计划

每条成片固定 6.00 秒：

| 时间 | 内容 | 要求 |
|---|---|---|
| 0.00–2.00 s | 快捷指令片头 | 展示用户正在使用苹果快捷指令；标题在此段出现 |
| 2.00–约 4.7 s | 食品拍摄/识别动作 | 让观众明确看到被识别的食品和操作动作 |
| 约 4.7–6.00 s | 热量识别结果 | 数值和食品名称清晰可见，结尾不拖沓 |

后 4 秒的内部切点可依素材微调，但必须同时保留“使用场景”和“识别结果”。录屏若包含自己的快捷指令开头，应裁掉，避免与独立片头重复。

先为每条视频写出可核对的 EDL/清单，包含：

- 拍摄录屏路径；
- 片头路径与片头入出点；
- 使用场景入出点；
- 识别结果入出点；
- 标题批次、编号与换行方式；
- 音乐路径；
- 输出文件名。

## 5. 标题设计

- 使用简体中文；仅按视觉宽度换行，不擅自改写标题库原文。
- 建议两行以内，白色粗体配不透明红色底块；以参考影片为准。
- 使用可商用中文无衬线字体，例如 Source Han Sans / 思源黑体。
- 标题位置应位于上方安全区，但避开快捷指令主图标、控制按钮、刘海/灵动岛和平台 UI 覆盖区。
- 标题可在 0.05 秒左右进入；结束时间不得晚于 2.00 秒。切入拍摄录屏后的第一帧不得残留标题或淡出影子。

## 6. 声音与音乐

- 从 `音乐` 目录轮换选择音乐，并裁切为 6 秒。
- 建议加入极短淡入和约 0.3 秒淡出，避免硬切爆音。
- 先检测拍摄录屏是否有有效声音。若为数字静音，不需要转写，也不要上传到转写服务。
- 若原声有实际价值，可在不影响音乐和可懂度的前提下混入；否则只保留音乐。
- 输出 AAC、48 kHz、双声道。发布向响度可参考约 -14 LUFS，真峰值不高于 -1.5 dBTP。

## 7. 预览与正式渲染

1. 先渲染 720x1280 预览。
2. 检查标题完整性、片头到实拍的 2.00 秒切点、实拍到识别结果的切点、画面裁切和声音。
3. 预览通过后，再用同一 EDL 渲染 1080x1920 正式版。
4. 建议使用 H.264、yuv420p、AAC、`+faststart`，保证抖音和小红书兼容。
5. 正式 MP4 只放在 `成品` 根目录；预览、字幕、帧图、清单和日志放入 `成品\_edit`。

## 8. QA 与证据

每条正式成片都要：

- 用 `ffprobe` 确认 1080x1920、60 fps、6.00 秒、H.264 + AAC；
- 完整解码音视频流，退出码必须为 0；
- 抽查片头标题帧；
- 抽查 2.00 秒前后，确认标题已消失且没有黑帧；
- 抽查识别结果段，确认热量数值可见；
- 检查音乐开头、结尾和音量；
- 记录实际标题、片头、音乐、输出文件和失败/修复次数。

只有上述检查真实完成后，才能报告成片完成。
